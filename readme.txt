jade.tools
==========

1. Распакуйте архив ЦЕЛИКОМ в постоянную папку (не в «Загрузки» вперемешку с
   другими файлами и не запускайте прямо из архива – сначала распакуйте всё
   содержимое в отдельную пустую папку).

2. Перемещать нужно всю папку целиком: jade.tools.exe не работает без папки
   _internal, которая лежит рядом с ним.

3. При первом запуске рядом с exe создадутся рабочие папки: bin, temp,
   cache, logs.

4. Если для какого-то инструмента не хватает компонентов (yt-dlp / ffmpeg /
   Deno) – приложение само это заметит и предложит варианты установки.

5. Антивирус может ложно пометить jade.tools.exe как угрозу – подробности и
   проверка на VirusTotal в README.md репозитория / на странице проекта.
