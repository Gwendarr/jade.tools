jade.tools
==========

1. Распакуйте архив в пустую папку и запустите jade.tools.exe (не запускайте прямо из
   архива – сначала распакуйте в пустую папку).

2. При первом запуске рядом с exe создадутся рабочие папки: bin, temp,
   cache, logs.

3. Если для какого-то инструмента не хватает компонентов (yt-dlp / ffmpeg /
   Deno) – приложение само это заметит и предложит варианты установки.
